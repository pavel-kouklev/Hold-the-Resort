# Hold the Resort — UI

Интерфейс живёт внутри мира: всё, что можно показать курортом, показываем курортом. На экране постоянно только 3 элемента; обучающего текста нет.

## Экран боя

```
┌──────────────────────────────────────────────────┐
│ [касса 0 347]                    ☀ ── дуга ──   ⏸ ×2 │
│                                                  │
│                 сцена локации                    │
│      (гости, персонал, объекты, нечисть)          │
│                                                  │
│ [открытка 2][открытка 3]                          │
└──────────────────────────────────────────────────┘
```

| Элемент | Состояния и как читаются |
| --- | --- |
| **Касса** (слева вверху) | Механический барабанный счётчик. Доход: монетка летит от объекта, барабан вверх, «дзынь». Трата: щелчок, барабан вниз. Не хватает: касса дёргается, звук пустого ящика |
| **Солнце / луна** (справа вверху) | Едет по дуге — время смены. На дуге одна метка — когда придёт босс. Рядом мелко пауза и ×2 |
| **Открытки** (слева внизу) | Живой мини-вид других локаций. Тревога: дрожит, красная рамка, иконка цели (гость / объект / башня). Последний гость там — луч прожектора. Тап — переход за 0,3 с. Закрытая — штамп «Скоро». PC: клавиши 1/2/3 |
| **Слот башни** | Пустой — меловой крестик. Тап — веер фото 3×4 с ценой ручкой, недоступные по деньгам блёклые. Тап по сотруднику — радиус и «уволить» |
| **Способность** | Медальон у сотрудника. Готова: пульсирует, инструмент в руке. Перезарядка: серый с круговой заливкой |
| **Объект развлечения** | Работает: огни, гости внутри, очередь видна людьми. Повреждён: трещины → дым. Выключен Кикиморой: темно, паутина. Сломан: табличка «Закрыто на ремонт» с ценой — тап чинит. Ремонт только в бою |
| **Интерактивный объект** | Готов: светится контур. Драг: полупрозрачный предмет + зона цвета эффекта. Перезарядка: объект «пустой» |
| **Нечисть** | Перед появлением: туман, вороны, вой у точки. Дух выбрал гостя — у гостя мигает «!» |
| **Гость** | Пиктограммы в стиле советских знаков: страх, лихорадка, Zzz. Уезжает — идёт с чемоданом к автобусу. Последний гость — луч прожектора, звук приглушён |
| **Событие** | Громкоговоритель на столбе вибрирует, в небе иконка события |
| **Босс** | Стоп-кадр 1,5 с, въезжает карточка в стиле Билибина с именем. Других заставок в бою нет |

Звук — часть UI: у каждой тревоги свой звук, слышен с другой локации.

## Межсменье

Межсменье — субботник на утреннем курорте, подробно — в `subbotnik.md`. Без меню и кнопок прокачки — всё делается на курорте.

| Шаг | Как выглядит |
| --- | --- |
| Книга отзывов | Рукописные записи спасённых гостей и победное фото; авторы выходят на курорт добровольцами с лопатами и вёдрами |
| Субботник | Драг добровольцев на объект → запускается наряд (мини-игра). Сломанный объект с табличкой «Закрыто на ремонт» не принимает добровольцев |
| Обход | Сторож (до него — Портье) идёт по следам нечисти, игрок заколачивает лаз |
| Расстановка | Перетаскивание объектов по площадкам и сотрудников по слотам; заявление нового специалиста — подпись |
| Старт смены | Гудок автобуса: приехал заезд; неиспользованные добровольцы уезжают |

После поражения — то же утро с уже сыгранными нарядами и обходом; менять можно только расстановку.

## Другие экраны

| Экран | Как выглядит |
| --- | --- |
| Карта / лобби | Туристическая схема курорта в виде плаката |
| Справочник нечисти | Удержание на духе — карточка в стиле Билибина. Единственное место с текстом, локализуется |
| Победа | Коллективное фото «на память», каждый раз новая сцена |
| Поражение | Пустой автобус уезжает, табличка «Мест нет» |

## Решения

- Постоянно на экране только касса, солнце/луна и открытки; счётчиков гостей, волн и HP нет.
- Деньги — цифра, стилизованная под кассу: без неё не сравнить цены.
- Метка босса на дуге — единственный индикатор волн.
- Объекты развлечений стоят на фиксированных площадках, свободной сетки нет.
